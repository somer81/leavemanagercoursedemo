## Files to change or add
Domain (`backend/app/domain/`):
- `auth.py` (yeni) — `Role` enum (EMPLOYEE / MANAGER / ADMIN), `Employee`, `Identity` (id, display_name, role) dataclass'ları
- `errors.py` — `InvalidCredentials`, `Unauthenticated`, `SessionExpired` eklenir

Repository (`backend/app/repositories/`):
- `schema.sql` (yeni) — `employees` (username UNIQUE, küçük harfle saklanır; display_name; role CHECK; manager_id FK; password_hash) ve `sessions` (token_hash PK, employee_id FK, created_at UTC ISO); `CREATE TABLE IF NOT EXISTS`
- `connection.py` — `connection_factory` yerine `Database`: `connect()` context manager (commit/rollback), `:memory:` için tek paylaşılan bağlantı, ilk başarılı bağlantıda şemayı uygular (idempotent); `PRAGMA foreign_keys = ON` ve `check_same_thread=False` korunur
- `health_repository.py` — `Database` kullanır (davranış aynı; 0001 testleri regresyon koruması)
- `employee_repository.py`, `session_repository.py` (yeni) — parametreli SQL; oturum anahtarı DB'de yalnızca SHA-256 özeti olarak tutulur

Servis (`backend/app/services/`):
- `clock.py` (yeni) — `Clock` Protocol (`now() -> datetime`, UTC)
- `passwords.py` (yeni) — `hashlib.scrypt` (n=2¹⁴, r=8, p=1, 16 bayt salt), `hash_password` / `verify_password` (`hmac.compare_digest`)
- `auth_service.py` (yeni) — `login`, `authenticate`, `logout`; biçim kuralları (kullanıcı adı 3–32 `a-z0-9._-`, parola 5–128); bilinmeyen kullanıcıda da sahte bir doğrulama yapılır (zamanlama farkı olmasın); 8 saat sınırı `Clock` ile
- `demo_users.py` (yeni) — seed mantığı: parola kontrolü önce, 4 kullanıcı tek transaction'da, var olanlara dokunmaz

API (`backend/app/api/`):
- `auth.py` (yeni) — `POST /api/auth/login` (200 + cookie), `POST /api/auth/logout` (204), `GET /api/auth/me` (200 `{display_name, role}`); `require_session` bağımlılığı; cookie `session`: `HttpOnly`, `SameSite=Strict`, `Path=/`, `Max-Age=28800`, `Secure` ayarla açılır
- `errors.py` (yeni) — tek exception handler: `InvalidCredentials`/`Unauthenticated`/`SessionExpired` → 401 (`INVALID_CREDENTIALS` / `UNAUTHENTICATED` / `SESSION_EXPIRED`), doğrulama hatası → 422 `INVALID_INPUT` **girdiyi geri yansıtmadan**, JSON olmayan POST → 415

- `backend/app/seed.py` (yeni) — `python -m app.seed`: `LEAVE_DB_PATH`, `DEMO_PASSWORD`; hata → çıkış kodu 1, parola yazdırılmaz

## Risks & open questions
- **R1 — Ortam (R-13).** Doctor @main: fast ve full **bu makinede çalışabilir**; yeni bağımlılık yok (yalnızca stdlib: `hashlib`, `hmac`, `secrets`). *Öneri:* kabul.
- **R2 — 0001 koduna dokunuluyor.** `connection.py` ve `health_repository.py` refaktör ediliyor (`:memory:` tuzağı). 0001'in 6 testi değişmeden yeşil kalmalı. *Öneri:* kabul; adım 1 ayrı commit.
- **R3 — Doğrulama hatası girdiyi yansıtır.** FastAPI'nin varsayılan 422 cevabı gönderilen değerleri (parola dahil) geri döner → AC-8 ihlali. *Öneri:* özel handler, `{"error":{"code":"INVALID_INPUT",…}}`, girdi yok.
- **R4 — 401 eşlemesi.** Konvansiyonlarda yalnızca 403 var. *Öneri:* oturum yok/süresi dolmuş/hatalı giriş → 401; başkasının verisi → 403 (değişmez).
- **R5 — JSON-only POST (415).** `docs/security.md` CSRF kuralı; kriteri yok ama belge-kod tutarlılığı (0001 F-1 dersi). *Öneri:* dahil et, bir uygunluk testiyle (`test_post_without_json_is_rejected`).
- **R6 — `Secure` cookie.** Yerelde http olduğundan varsayılan kapalı; `LEAVE_COOKIE_SECURE=1` ile açılır, README production notu. *Öneri:* kabul.
- **R7 — scrypt maliyeti.** ~50 ms/hash; testlerde ~30 hash → ~1,5 s. *Öneri:* gerçek parametreler (test için zayıflatma yok); süre medyanı Build evidence'ta.
- **R8 — Hassas alan kanıtı.** VERIFY her kriteri bir kasıtlı bozmayla kanıtlar (≈10 bozma, depo dışı klonda). *Öneri:* kabul.
